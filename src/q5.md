# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
```text
Core OS that manages the computer's hardware and resources, CPU, RAM, etc. Allows the app to interact with the hardware.
```

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
```text
They are not totally independent. Windows Subsystem for Linux runs inside Windows. It uses a lightweight VM. It can interact with Windows files, folders and app and Windows can also access files within the WSL.
```
---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
Terminal is the area where the user types in command to interact and see the output, whilst shell is the programme that interprets and executes the commands.
